# 추천 파티 조합

## ⚙ 무과금 현실 조합 — 레바테인 없을 때 대안

![Image Alt 텍스트](/assets/img/game/20260423/5.png) <br>

| **캐릭터**      | **획득 방법**  | **특징 / 역할**                                       |
| -------- | ------ | --------------------------------------------- |
| 관리자(주인공) | 기본 배포  | 물리 속성이라 상성 무관. 넉다운 CC로 보스 패턴 차단. 무료이면서 T1급 성능 |
| 포그라니치니크  | 상시     | 돌진 그로기로 빠른 보스 무력화. AIC 창고 용량도 증가              |
| 아델리아     | 무료 10일 | 주인공의 딜을 증폭시키고 생존 보조                           |
| 진천우      | 배포 5성  | 탱킹 + 어그로 관리. 초·중반 안정적인 전선 유지                  |

> 한정 캐릭터 없이도 스토리 클리어에 충분한 구성입니다. 초반엔 이 조합으로 시작해 이성을 모아 레바테인을 노리세요.

## 🔥 화염 최강 조합 — 레바테인 파티 (무과금 접근성 최고)

![Image Alt 텍스트](/assets/img/game/20260423/10.png) <br>

![Image Alt 텍스트](/assets/img/game/20260423/11.png) <br>

| **캐릭터**  | **획득 방법**  | **특징 / 역할**                                       |
| ---- | ------ | --------------------------------------------- |
| 레바테인 | 한정     | 메인 딜러. 직접 조작 추천. 열기 흡수 → 4스택 → 배틀스킬 폭발 사이클 반복 |
| 울프가드 | 배포     | 레바테인의 대체 불가 파츠. 궁극기로 열기 부착, 아츠 취약 디버프 제공      |
| 아델리아 | 무료 10일 | 부식으로 적 방·마저 감소. 힐링 장판 제공. 레바 딜 1.5배 증폭 핵심 서포터 |
| 아케쿠리 | 4성 상시  | SP 충전 전문가. 광역 열기 부여로 울프가드 연계 촉진. 4성이라 획득 쉬움   |

> 운영: 레바 평타 → 아케쿠리 배틀스킬 → 울프가드 연계스킬 → 아델리아 연계+배틀스킬 반복. 4스택 달성 시 레바테인 배틀스킬 발동.

## ❄ 냉기 시너지 조합 — 이본 파티 (빙결 폭발 쾌감)

| **캐릭터**     | **획득 방법**  | **특징 / 역할**                                    |
| ------- | ------ | ------------------------------------------ |
| 이본      | 한정     | 빙결된 적에게 확정 치명타 궁극기 발동. 냉기 파티 핵심 딜러         |
| 라스트 라이트 | 상시     | 냉기 파티의 근접 딜러. 이본과의 조합 시너지가 최강              |
| 질베르타    | 한정     | 적을 중력장으로 몰아주는 CC. 한 곳에 모인 적을 이본이 빙결 폭발로 전멸 |
| 아델리아    | 무료 10일 | 속성 불문 활약하는 유틸 서포터. 냉기 파티에도 부식 디버프와 힐이 필수   |

> 질베르타로 모으기 → 알레쉬로 얼리기 → 이본 궁극기 확정 치명타 폭발. 절정의 쾌감이 있는 콤보입니다.

# 초보자 성장 로드맵

## 🎯 STEP 1 — 리세마라 & 초반 설정

```
목표 캐릭터(레바테인 우선) 리세마라 후 시작. 
리딤 코드 즉시 입력. 
45레벨 보상 6성 무기 선택권은 메인 딜러 전용 무기에 사용하세요.
```

## ⚔ STEP 2 — 메인 스토리 & 오픈월드 탐험

```
스토리를 진행하며 재화를 수급합니다. 
희귀 채집물과 광물은 매일 오전 4시 리셋되므로 하루 한 번 채집 루틴을 잡으세요. 
'업무 알림'에서 오늘 할 일을 확인하세요.
```

## 💎 STEP 3 — 아델리아 확보 & 파티 완성

![Image Alt 텍스트](/assets/img/game/20260423/7.png) <br>

```
10일 로그인으로 아델리아 + 전용 무기를 무료 획득합니다. 
레바테인 파티라면 울프가드(배포) + 아케쿠리(4성 상시)를 추가해 파티를 완성하세요.
```

## 🏭 STEP 4 — AIC 공장 기초 구축

```
기본 자원 자동화 라인 구축. 
커뮤니티 청사진을 참고하면 초보자도 쉽게 시작할 수 있습니다. 
공장 없이는 상위 장비 제작이 불가능하므로 빠를수록 좋습니다.
```

## ⚔ STEP 5 — 고난도 콘텐츠 도전

```
원소 반응을 마스터하고 보스 패턴을 익힌 후 고난도 구역에 도전합니다. 
연소·응고 같은 원소 반응 이해가 고레벨 캐릭터보다 더 중요합니다.
```

## 🎰 STEP 6 — 재화 모아 다음 한정 픽업 준비

![Image Alt 텍스트](/assets/img/game/20260423/9.png) <br>

```
합성옥을 한정 픽업에 집중 투자. 
여기저기 낭비하지 말고 천장(80번)을 목표로 저축합니다. 
상시 캐릭터는 이벤트 보상으로 서서히 확보해 가세요.
```

# 무과금 재화 수급

## 💡 엔드필드 무과금의 핵심 — 파생 오리지늄(합성옥)

![Image Alt 텍스트](/assets/img/game/20260423/0.png) <br>

![Image Alt 텍스트](/assets/img/game/20260423/1.png) <br>

주요 뽑기 재화는 **'합성옥'**과 **'오로베릴'**입니다. <br>
무과금·소과금 유저는 파생 오리지늄을 미리 모아두는 것이 중요합니다. <br>
매 3주마다 새 배너가 교체되므로 목표를 미리 정하고 재화를 집중해야 합니다. <br>

<br>

## 주요 재화 수급처

| **수급처**        | **내용**                                      | **우선도**   |
| ---------- | --------------------------------------- | ----- |
| 메인 스토리 진행  | 각 스테이지 클리어 시 합성옥·오로베릴 지급. 가장 기본적인 수급 루트 | ⭐⭐⭐⭐⭐ |
| 10일 로그인 보상 | 아델리아(6성) + 전용 무기 확정 지급. 반드시 출석 챙기기      | ⭐⭐⭐⭐⭐ |
| 오픈월드 탐험    | 보물 상자, 오리렌(오리지늄 원석), 희귀 광물 채집으로 재화 수급   | ⭐⭐⭐⭐  |
| 일일 미션      | 매일 소량이지만 꾸준히 모으면 상당한 양. 데일리 루틴 필수       | ⭐⭐⭐⭐  |
| 업적 달성      | 일회성이지만 대량 지급. 가능한 한 빠르게 업적 달성           | ⭐⭐⭐⭐  |
| 이벤트 참여     | 기간 한정 이벤트에서 오로베릴·합성옥 대량 수급 가능           | ⭐⭐⭐⭐  |
| 리딤 코드 입력   | 공식 SNS·커뮤니티에서 비정기 배포. 즉시 입력 필수          | ⭐⭐⭐   |
| AIC 지역 관리권 | 공장 생산 → 판매 → 재화 교환. 안정적 장기 수급 루트        | ⭐⭐⭐   |

# 무과금으로 직접 해본 후기

무과금 측면에서는 생각보다 친절한 편입니다. <br>
아델리아라는 6성 서포터를 출석 10일 체크로 무료로 받을 수 있고, 울프가드는 배포 5성으로 지급됩니다. <br>

초반 뽑기 재화도 스토리 진행과 탐험만으로 40~50회 분량은 충분히 모을 수 있습니다. <br>
다만 레바테인이나 질베르타 같은 한정 캐릭터를 놓치면 메타에서 한 발 뒤처지는 느낌은 솔직히 있습니다. <br>
