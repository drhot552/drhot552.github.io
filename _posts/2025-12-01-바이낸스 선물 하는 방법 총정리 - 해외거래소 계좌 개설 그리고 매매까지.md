# 선물과 레버리지란
선물은 미래 가격을 맞추는 게임입니다. 즉, 미래에 가격이 상승이냐 하락을 맞추는 게임이죠. <br>
과거 주식시장이 생기고 난 이후 유대인이 만든 게임에 레버리지를 더했다 생각하면 되요.<br>

- 롱 : 미래에 가격 상승 
- 숏 : 미래에 가격 하락

이에요. <br>

이때 선물은 레버리지를 사용이 가능한데 말그대로 빚을 내서 투자한 자산을 더 높이 설정이 가능합니다. <br>

> 즉, 선물은 주식이나 코인을 실제로 사고파는 것이 아니라, 미래 가격에 대한 **'약속 증서(계약 - 롱,숏)'**를 사고파는 것입니다.

# 바이낸스 계좌 생성과 거래소 입금 방법
먼저 암호화폐 선물거래는 해외거래소에서만 지원가능하기 때문에 해외거래소 중 1등인 **바이낸스의 회원가입과 돈을 입금하는 방법**에 대해서 알려드릴게요.

<br>
<br>

## 1. 바이낸스 회원가입
먼저 해외거래소를 사용하기 위해선 준비물이 필요해요. <br>

| 준비물                     | 용도     |
| ---------------------- | ---------------- |
| 이메일 주소  | 계정 생성 및 인증에 필수    |
| 휴대폰 | 전화번호 인증 및 2단계 인증(2FA)에 필수 |
| 여권 (Passport) / 주민등록 / 운전면허증 | KYC 신원인증 필수 |

<br>

![Image Alt 텍스트](/assets/img/crypto/251201/1.png){: width="80%" height="80%"}<br>

- **ID CARD(추천)** : 주민등록증 
- PASSPORT : 여권
- Driver's License : 운전면허증
- Residence Permit : 거주 허가증 (국내에선 해당 X)

> 사진으로 찍어서 여권으로 인증 받는게 가장 빠르게 인증할 수 있어요.

<br>
<br>

# 바이낸스 선물 투자하는 방법
바이낸스에서 매매하는건 크게 두가지에요. **(Spot / Future)** <br>

- Spot(지정가거래) : 현물 거래
- Future(미래가격거래) : 선물거래

<br>

## 2. 🛠️ 바이낸스 선물 거래 화면 기능 상세 분석

![Image Alt 텍스트](/assets/img/crypto/251201/8.png){: width="80%" height="80%"}<br>

제시된 화면은 선물 계약을 체결하기 전, **레버리지 설정**과 **주문 유형, 위험 관리**를 설정하는 단계입니다.

<br>
<br>

## 포지션 및 레버리지 설정

| 기능 | 마진/레버리지 | 설명 |
| :--- | :--- | :--- |
| **Cross/Isolated** | 교차(Cross) / 격리(Isolated) | **교차 마진(Cross)**은 지갑의 모든 잔액을 증거금으로 사용하며, **격리 마진(Isolated)**은 해당 포지션에 투입된 증거금만 사용합니다. |
| **20x** | 레버리지 배율 | **지렛대 배율**입니다. 현재 **20배**로 설정되어 있으며, 배율이 높을수록 수익과 손실, 그리고 청산 위험이 커집니다. |
| **Limit / Market / Stop Limit** | 주문 유형 | **Limit(지정가)**: 원하는 가격에 도달하면 체결. **Market(시장가)**: 즉시 시장 가격으로 체결. **Stop Limit**: 특정 조건 충족 시 지정가 주문 발동. |

<br>
<br>

## 주문 규모 및 잔액 정보

| 기능 | 영어 명칭 | 설명 |
| :--- | :--- | :--- |
| **Avbl 13.33 USDT** | Available Balance | 현재 선물 지갑에서 **사용 가능한 잔액**입니다. (증거금으로 투입 가능한 금액) |
| **Price (91,498.0 USDT)** | 가격 | **지정가 주문** 시, 포지션 진입을 원하는 가격을 입력하는 곳입니다. |
| **Size (100% USDT)** | 규모 | 포지션에 투입할 **증거금의 비율**입니다. 슬라이더를 이용하여 가용 잔액 중 몇 %를 사용할지 설정합니다. |
| **Buy/Long, Sell/Short** | 포지션 방향 | **Buy/Long**: 가격 **상승**에 베팅 (매수). **Sell/Short**: 가격 **하락**에 베팅 (매도). |

<br>
<br>

## 위험 관리 설정 (필수 확인)

TP/SL은 트레이딩에서 손실을 방지하고 이익을 확정하는 **가장 중요한 안전 장치**입니다. <br>

| 기능 | 영어 명칭 | 설명 |
| :--- | :--- | :--- |
| **TP** | **Take Profit (이익 실현)** | 지정한 가격에 도달하면 **수익 상태로 자동 포지션 종료** (수익 확정) |
| **SL** | **Stop Loss (손실 제한)** | 지정한 가격에 도달하면 **자동으로 포지션을 종료하여 손실을 제한** (최대 손실폭 설정) |
| **Reduce-Only** | 축소 전용 | 포지션의 규모를 **줄이는 역할**만 하도록 설정합니다. 실수로 포지션을 반대로 잡는 것을 방지합니다. |

<br>
<br>

## 최종 확인 및 청산 정보 (매우중요!!)

포지션 체결 버튼을 누르기 전에 반드시 확인해야 할, 투자에 직결되는 정보입니다. <br>

| 기능 | 영어 명칭 | 설명 |
| :--- | :--- | :--- |
| **Liq Price** | **Liquidation Price (청산 가격)** | 시장 가격이 이 가격에 도달하면, **강제로 포지션이 종료되며 증거금을 모두 잃게 됩니다.** (롱/숏 포지션 별로 다름) |
| **Cost** | **증거금 비용** | 해당 레버리지와 규모로 포지션을 개설하기 위해 **실제 필요한 최소 증거금**입니다. |


> 가장 중요한건, **TP/LS**입니다. 즉 지정가격에 자동으로 체결되는건데요. LS를 꼭 거셔야 청산에 대한 리스크 관리를 할 수 있어요!

# 필요한 건 리스크 관리
원래 선물은 현물거래의 헷징 기능으로 사용했던 방식이었어요. <br> 
하지만, 레버리지가 들어가게 되면서 점점 헷징의 개념보단 도박의 기능으로 들어가게 됬습니다. <br>

때문에, 심리적인 흔들림이나 휩쏘가 나오게 되면 금방 돈을 잃게 되는 구조에요. <br>

1. 청산 가격 확인 필수 (Liq Price)
2. 손절매(Stop Loss, SL) 설정 의무화
3. 낮은 레버리지 사용
4. 감당 가능한 금액만 투입 (여윳돈)



**※ 매수 매도 추천은 절대 아니며, 투자 전에는 반드시 본인의 판단과 리스크 관리가 필요합니다.**
