# 

![Image Alt 텍스트](/assets/img/game/20260404/2.png) <br>

마비노기 모바일은 **룬으로 아이템을 업그레이드**되는 룬 기반 시스템을 채택하고 있습니다.  <br>
즉, 아이템보단 룬으로 전투력을 올릴 수 있어 자유도가 매우 높은게 특징이에요. <br>

<br>

현재 게임에는 룬은 고급, 엘리트, 에픽, 전설, 신화의 **5개의 등급**이 존재합니다. <br>
당연히 신화로 갈수록 아이템은 더 좋아지고, 전설 부터 얻기가 힘들어요.  <br>

```
💡 핵심 포인트  
레벨이 높아질수록 룬 승급으로 좋은 아이템 착용 
→ 룬 승급 활용
```

> 룬 등급만 높으면 퀘스트 깨는데는 큰 문제는 없습니다.

# 마비노기 룬 아이템

룬은 고급, 엘리트, 에픽, 전설, 신화로 갈수록 장비가 점점 더 성능이 좋아집니다. <br>

**현재 메타 기준** (레이드 / 어비스 / 균열 종합) <br>

| **티어**  | **룬 종류**            | **핵심 효과**   |
| ------- | ------------------- | ----------- |
| **0티어** | 치명, 공격력 증가, 스킬 증폭   | 모든 딜러 공통 필수 |
| **1티어** | 쿨감, 자원 회복, 보스 추가 피해 | 콘텐츠 특화      |
| **2티어** | 방어, 체력, 상태이상 저항     | 안정성         |
| **3티어** | 이동속도, 유틸            | 효율 낮음       |

<br>

```
🏆 메타 요약  
치명 + 공격력 = 기본 세팅  
쿨감 = 딜 사이클 완성  
보스 피해 = 레이드 필수
```

<br>

# 룬 추천 세팅 (수도사 기준)

![Image Alt 텍스트](/assets/img/game/20260404/1.png) <br>

수도사는 **지속 딜 + 스킬 회전율 + 안정성**이 핵심입니다. <br>
즉, 한방보다는 “계속 때리는 구조”가 중요합니다. <br>

<br>

## 1. 무기

![Image Alt 텍스트](/assets/img/game/20260404/3.png) <br>

저는 사실 무기로는 무조건 공격력이 높은 무기로 아이템을 끼고 룬 승급에 초점을 맞췄는데요. <br>
저같이 초보자들에겐 굳이 **룬 속성보단 룬의 등급**을 보고 맞추는게 가장 좋아요. <br>
무기 뿐 만아니라 나머지 방어구 장신구도 마찬가지 입니다. <br>

<br>

⚔️ 추천 무기 및 룬 조합 

| **무기**         | **추천 룬** | **이유**              |
| ---------- | ---- | --------------- |
| 폭풍 완드 (전설) | 폭풍 룬 | 광역 스킬 위력 30% 증가 |
| 신성 완드 (에픽) | 강타 룬 | 단일 보스 딜 안정적     |
| 심연 완드 (에픽) | 뇌격 룬 | 지속 딜 극대화        |

<br>

```
💡 무기 강화 팁
완드는 +10 이상부터 성능 차이가 급격히 벌어집니다.
→ 강화 재료 부족 시 에픽 완드 +15 유지 추천
→ 전설 무기 파밍이 가능해지면 즉시 교체
```

<br>

## 2. 방어구 (모자, 갑옷, 장갑 등)

![Image Alt 텍스트](/assets/img/game/20260404/4.png) <br>

방어구는 생존력과 스킬 쿨다운 감소에 영향을 미치며, 룬 조합에 따라 공격적인 세팅과 생존 세팅으로 나뉩니다.
<br>
물론 저는 방어력 높은 애들 먼저 룬 등급높은거 세팅해서 장착했어요. <br>

<br>

🛡️ 추천 방어구 및 룬 세팅

| **부위** | **추천 장비**      | **추천 룬** | **효과**               |
| -- | ---------- | ---- | ---------------- |
| 모자 | 신성 두건 (에픽) | 집중 룬 | 스킬 쿨다운 감소        |
| 갑옷 | 폭풍 로브 (전설) | 쇄도 룬 | 이동속도 · 연속딜 증가    |
| 장갑 | 심연 장갑 (에픽) | 분노 룬 | HP 50% 이하 시 딜 증가 |

<br>

```
💡 방어구 세팅 팁
생존이 불안하면 회복룬을 장갑에 장착해 딜-탱 균형 조절 가능
→ 어비스·레이드 진입 후 점차 공격형으로 교체 추천
```

<br>

## 3. 장신구 (반지, 목걸이)

![Image Alt 텍스트](/assets/img/game/20260404/5.png) <br>

장신구는 스탯 증폭과 특수 효과를 담당하며, 수도사의 경우 치명타와 스킬 위력 관련 룬이 핵심입니다.
<br>

**💍 추천 장신구 및 룬 조합**

| **부위**  | **추천 장비**        | **추천 룬** | **효과**              |
| --- | ------------ | ---- | --------------- |
| 반지  | 폭풍의 반지 (전설)  | 뇌격 룬 | 감전 추가 피해 20% 증가 |
| 목걸이 | 신성의 목걸이 (에픽) | 강타 룬 | 보스 단일딜 집중 증가    |

<br>

> 장신구는 전설 등급 파밍이 가장 어려운 부위입니다. 에픽 등급으로도 충분히 콘텐츠 진입이 가능하니 무리한 파밍보다 안정적인 강화를 우선하세요.

<br>

## 4. 엠블럼

![Image Alt 텍스트](/assets/img/game/20260404/6.png) <br>

엠블럼은 클래스 레벨 달성 시 획득하는 클래스 메달로 교환할 수 있으며, 직업별 고유 능력치를 크게 강화합니다.
<br>
엠블럼은 다른 아이템과 다르게 클래스 레벨업을 할 수 있기 때문에, 룬에 크게 종속되진 않습니다. <br>

<br>

**🏅 수도사 추천 엠블럼 우선순위**

| **순위**  | **엠블럼**    | **효과**            | **추천 이유**       |
| --- | ------ | ------------- | ----------- |
| 1순위 | 폭풍 엠블럼 | 광역 스킬 위력 +15% | 어비스 · 균열 핵심 |
| 2순위 | 강타 엠블럼 | 보스 피해 +12%    | 레이드 딜 증가    |
| 3순위 | 신성 엠블럼 | HP 회복량 +10%   | 솔로 생존력 보완   |

<br>

```
💡 엠블럼 획득 방법
클래스 레벨 25·35·45·55·65 달성 시 클래스 메달 획득
→ 5개 모으면 원하는 클래스 엠블럼으로 교환
→ 부캐 활용 시 메달 수급 효율 극대화 가능
```

<br>

## 🏆 최종 추천 세팅

![Image Alt 텍스트](/assets/img/game/20260404/0.png) <br>

* 무기: 치명 + 공격력 + 스킬 증폭
* 방어구: 쿨감 + 생존
* 장신구: 치명 피해 + 보스 피해
* 엠블럼: 치명 특화

<br>

**“세팅 싸움” 게임입니다.**

<br>
