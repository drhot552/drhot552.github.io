![Image Alt 텍스트](/assets/img/review/20260329/1.png) <br>

예식장은 참고로 1년전부터 예약하는게 가장 좋습니다. <br>
거진 다 마감이에요. <br>
참고로 저흰 아펠가모로 했고, 예약은 인터넷에서 바로했습니다.(아펠가모 장점) <br>

```
인터넷 예약으로 진행
1년전에 해야 좋은 날짜 시간에 할 수 있음. (1년전도 좀 빠듯해요.)
금액은 보통 400-500만원 선 (이것도 예약할때 다를 수 있음)
```

<br>

예식장 관련해서 후기는 본식 이후 다시한번 더 작성할게요. <br>

> 금액은 매년 달라지니, 아펠가모 홈페이지에서 꼭 확인하세요!

# 플래너 (+스드메)
플래너는 업체가 많고, 업체 및 계약사항을 공개하면 안되서 이 부분은 대략적인 금액만 적어놓을게요. <br>
업체마다 다르기 때문에 개인차가 크다고 봅니다. <br>
보통 직장인이나 일상이 바쁜 분들에게는 플래너 끼는게 좋아요. <br>

```
기본적 스드메 가격 (300만원 이상)
스튜디오 - 80만원 이상 
드레스 - 100만원 이상 (드레스투어 X, 드레스 투어하면 돈 더들어감) 
메이크업 - 80만원 이상
(+플래너 비용 a)
```

이것도 거의 가성비로 했을때고, 막상해보면 다릅니다. <br>
가성비는 별로인게 좀 많아서 아무래도 평균적으로 하면 400만원 이상은 생각하는게 맞아요. <br>
아마 스드메를 하기로 했으면 너무 가성비는 마음에 안드실거에요. <br>

> 스드메는 보통 플래너를 통해서 하는 업체면 좀 더 할인이 들어갑니다. (이건 업체마다 상이함)

# 스드메 기타 (드레스)
스드메에 추가 기타 비용이 발생해요. <br>

```
스튜디오 추가 시간
드레스 투어 (드레스 지정으로 하면 발생 x)
촬영용 드레스 추가시 (기본 3벌 + a)
촬영때 이모님 비용 + 간식 (20만원 + a)
```

대략 이것만 100만원은 넉넉히 잡으시는게 좋습니다.<br>
전 예부랑 어느정도 양보해서 이모님 비용말곤 발생안햇어요. <br>

# 한복

![Image Alt 텍스트](/assets/img/review/20260329/3.png) <br>

한복은 양가로 대여했는데, 이것도 플래너 업체 껴서 10%할인 받았어요. <br>
그래도 가격이 싸진않았습니다. <br>
물론 한복도 구매하면 더비쌉니다. <br>

```
양가 한복 대여 : 100만원 이상
```

> 한복은 양가 부모님들의 의견이 매우 중요해서 아무래도 가격보단 이 포인트가 가장 중요할거 같습니다.

## 총 비용
| 구분           | 금액                  |
| ------------ | ------------------- |
| **최소 합계**    | **1,800만원**         |
| **현실 평균 합계** | **2,000 ~ 2,450만원** |

```
최소로 맞춰도 약 1,800만원
평균적으로는 2,000만원 이상은 거의 확정 
웨딩밴드 + 스드메에서 비용 차이가 가장 크게 발생
“가성비”로 시작해도 결국 추가 비용 발생하는 구조
```

> 참고로 저건 매우 보수적으로 잡은거에요. 신혼여행이나 상견례 등등 여러 추가 비용까지 하면 아무래도 더 비용이 든다고 생각하는게 맞습니다.
