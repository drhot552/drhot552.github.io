# S등급 무기 심층 비교

S등급 무기 3종을 자세히 비교합니다. 자신의 플레이 스타일과 파밍 상황에 맞게 선택하세요. <br>

![Image Alt 텍스트](/assets/img/game/20260418/9.png) <br>

- 공격 방식: 가장 가까운 적을 향해 검이 늘어났다가 돌아오며 근처 적을 자동 공격 
- 핵심 스킬: 족쇄 — 처치한 적의 영혼을 가둬 스킬 피해 최대 30% 증가. 피격 시 영혼 소산 주의
- 레전드 추가: 용혼 폭발 — 영혼 100 감소 시 전체 화면 광역 대미지

> 💡 압사 방지를 위해 수호자 필수 동반 추천

<br>

![Image Alt 텍스트](/assets/img/game/20260418/10.png) <br>

- 공격 방식: 블랙홀 2개 생성, 적 흡수 + 폭발. 실드로 근접 공격 무효화
- 핵심 스킬: 파괴 본성 — HP 20% 이하 적 즉사(보스 제외). 혈맥 억제 — 엘리트/보스에 피해 50% 증가
- 신의 주조: 대량 효과(블랙홀 합성) → 공격력 +20% → 에너지 붕괴(합성 블랙홀 피해 증가)

> 💡 단순히 챕터를 밀고 싶다면 파괴의 힘 추천. 에픽만 해도 챕터 충분

<br>

![Image Alt 텍스트](/assets/img/game/20260418/11.png) <br>

- 공격 방식: 전방 검기 난사. 돌파 시 검기 2배 + 범위 인게임 최강 수준
- 핵심 스킬: 매 5회 공격마다 회전 베기. 공격력 +25%. 범위 광역 처리 
- 신의 주조: 어검술(검열 1개 추가) → 공격력 +20% → 거대검술(검열이 시간에 따라 커짐)

> 💡 7일 카니발 1500훈장 달성 시 엘리트 획득 가능. 신규 유저 진입 장벽 낮음

<br>

```
✅ 무기 선택 가이드 
컨트롤 자신 없는 초보 → 쿠나이(자동 조준) 또는 파괴의 힘(실드 안전)
챕터를 빠르게 밀고 싶다면 → 파괴의 힘 에픽으로 충분
잡몹 광역 처리 특화 → 빛을 쫓는 자 (돌파 후 범위 최강)
보스전·종말의 메아리 특화 → 혼돈의 검 (자동 조준 + 보스 집중 딜)
S등급 없는 경우 → 야구방망이 레전드 (360° 범위, S급 아닌데 강력)
```

# 초보자 성장 로드맵

![Image Alt 텍스트](/assets/img/game/20260418/13.png) <br>

처음 탕탕특공대를 시작한다면 아래 순서로 진행하는 것을 추천합니다. <br>

## 🎁 STEP 1 — 카니발 시작 & 7일 미션 집중

```
게임 시작 즉시 카니발 진행 여부를 확인합니다. 
7일 미션을 매일 완료해 훈장을 쌓으세요. 
700훈장 → 영원의 전투복(엘리트) 획득이 1차 목표입니다. 
게임이 크게 수월해집니다.
```

## ⚔ STEP 2 — 쿠나이 중심으로 챕터 진행

```
S등급 무기가 없다면 쿠나이(자동 조준)를 중심으로 키웁니다. 
야구방망이도 S급 없을 때 좋은 대안입니다. 
챕터를 밀면서 보석과 장비 재료를 쌓아갑니다.
```

## 🔫 STEP 3 — S등급 무기 확보

```
카니발 1,500훈장 달성 시 빛을 쫓는 자 확보 가능합니다. 
보석은 50뽑 기준으로 S급 무기 목표로 절약합니다. 
파괴의 힘·혼돈의 검은 뽑기 또는 이벤트 보상으로 노립니다.
```

## 🛡 STEP 4 — 방어구 세트 구성

```
영원의 전투복 엘리트(카니발 보상)를 기반으로 유행 벨트, 에너지 러닝화 등 비S급 1티어 장비부터 맞춥니다. 
이후 영원의 장갑, 영원의 목걸이 순으로 S급 방어구를 채워갑니다.
```

## ⬆ STEP 5 — 합성으로 에픽 목표

```
무기·방어구 모두 에픽(노랑)이 챕터 진행의 현실적 목표입니다. 
S등급 무기 에픽이면 챕터 진행에 무리가 없습니다. 
레전드는 소과금 이상 장기 목표로 설정하세요.
```

## 🌟 STEP 6 — 신의 주조 시작

```
레전드 달성 후 신의 주조를 진행합니다. 
우선순위는 영원의 장갑 1주조(치명타 회복) → 영원의 목걸이 1주조(패시브 돌파) 순서로 진행합니다. 
재료 소모가 크므로 목표를 정하고 집중 투자하세요.
```
