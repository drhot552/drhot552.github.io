### 피스네트워크(PYTH) 유틸리티
피스네트워크의 유틸리티는 일반적인 거버넌스 기능과 스테이킹 기능이 있고, 앞으로도 토큰 유틸리티를 늘리고 있는 상황입니다. <br>

1. 데이터 소비 비용 지불
- 디앱(DApp), 거래소, 디파이 서비스가 Pyth의 데이터를 사용할 때 수수료를 PYTH로 지불
2. 데이터 제공자 보상
- 거래소, 마켓메이커 같은 데이터 공급자가 네트워크에 가격 데이터를 제공하면 PYTH로 보상
3. 스테이킹 (Staking)
- PYTH를 스테이킹하면 네트워크 안정성을 높이고, 데이터 품질을 보장하는 역할
4. 거버넌스 참여
- PYTH 보유자는 네트워크 업그레이드, 파라미터 조정, 보상 구조 변경 등에 투표
5. 네트워크 보안 강화
- 스테이킹 기반으로 “정직한 데이터 제공”을 유도하는 구조라, 토큰이 보안 장치 역할


> "데이터를 소비하는 쪽은 비용을 지불하고, 제공하는 쪽은 보상을 받는 구조"로 설계되어, 오라클 데이터 경제의 순환을 만드는 것이 핵심이에요.

## 피스네트워크(PYTH), 뭘하려는 걸까?
Pyth는 탈중앙화된 오라클 네트워크로, 실시간 **금융 시장 데이터(암호화폐, 주식, 환율 등)**를 블록체인에 전달해주는 역할을 합니다. <br>
솔라나 기반으로 시작되었고, 고빈도 데이터 제공에 특화된 기술을 갖고 있어요. <br>

<br>

### 필요한 이유가 무엇일까? 
블록체인 안에서는 가격 데이터를 직접 알 수가 없어요. <br>

```
예를 들어, 디파이(DeFi) 서비스에서 
“지금 애플 주식이 얼마인지”, 
“비트코인 시세가 몇 달러인지” 같은 데이터를 알아야 스마트컨트랙트를 실행이 가능합니다.
```

> 그런데 블록체인 자체는 이런 외부 데이터를 알 수 없으니, 누군가가 “정확한 데이터”를 안전하게 공급해야 하는 거예요. 여기서 등장하는 게 바로 **피스네트워크**입니다.


## 오라클 네트워크가 주목받는 이유는?
오라클 네트워크가 주목받는건 RWA가 주목받으면서 블록체인만으로는 현실 세계 데이터 확인 불가하기 때문이에요.  <br>

즉, 블록체인은 탈중앙화된 장부라서 스스로 외부 데이터를 확인할 수 없기 때문에, 여기서 **오라클(Oracle)**이 필요한 거예요. <br>
외부 데이터를 블록체인에 안전하게 공급하는 다리 역할을 합니다. <br>

## 피스네트워크 vs 체인링크
대표적으로 오라클 네트워크하면 체인링크가 생각이 나죠. 때문에 체인링크와 한번 비교해봤습니다.

| 구분          | 체인링크(Chainlink)              | 피스네트워크(Pyth)                        |
| ----------- | ---------------------------- | ----------------------------------- |
| **출시 시기**   | 2017년                        | 2022년                               |
| **주요 목표**   | 다양한 블록체인과 스마트컨트랙트에 범용 데이터 공급 | 금융 데이터, 특히 실시간 가격 데이터에 특화           |
| **데이터 공급자** | 누구나 노드 운영 가능, 다양한 공급자 참여     | 주로 **거래소, 금융 기관** 중심, 신뢰도 높은 데이터 제공 |
| **데이터 유형**  | 가격, 이벤트, API, 날씨, 스포츠 등 범용   | 주식, 암호화폐, 외환, 원자재 등 금융 시장 중심        |
| **토큰 활용**   | LINK: 노드 보상, 스테이킹, 거버넌스 일부   | PYTH: 데이터 사용료, 제공자 보상, 거버넌스, 스테이킹   |
| **확장성**     | 다양한 체인과 앱, 범용                | 금융 데이터에 특화, 체인별 커스터마이징 필요           |

쉽게 이해하면 <br>

- **체인링크** = 범용 오라클 플랫폼 → 다양한 데이터 + 다양한 블록체인
- **피스네트워크** = 금융 데이터 특화 오라클 → 고속·실시간 금융 데이터 공급에 최적화

즉, 체인링크는 여러 분야에서 쓰이는 **‘올라운더’**, **피스네트워크는 금융 시장에 최적화된 ‘전문가’**라고 생각하면 돼요. <br>

> 체인링크는 범용 오라클, 피스네트워크는 실시간 금융 데이터에 특화된 오라클로, 둘 다 스마트컨트랙트 데이터 공급의 핵심 인프라지만 쓰임새가 조금 다릅니다.

## 미국 상무부 피스네트워크 언급?
최근 미국 상무부에서 체인링크와 피스네트워크에 대한 언급이 있었습니다. 하지만 논란은 분명 있어요. 잘 보고 투자가 필요합니다.

- 미국 상무부는 체인링크와 피스네트워크를 선정하여 공식 경제 데이터를 블록체인에 게시하는 프로젝트를 발표
- 체인링크는 BEA(미국 경제 상황을 수치)로부터의 데이터를 수집하여 블록체인에 게시하며, 피스네트워크는 직접 GDP 데이터를 수집하여 게시
- 이번 프로젝트는 정부 데이터의 투명성과 접근성을 높이고, 블록체인 기술을 활용한 다양한 응용 가능성을 제시

이로인해, 피스네트워크는 발표전 대비 **100%이상이 급등**하는 모습을 보여줬습니다. <br>
 
> 그러나, 피스네트워크 CEO가 있지도 않은 백악관 보도자료를 사칭하며 자신들이 백악관 독점 보도자료에 유일하게 인용했다는 얘기가 돌면서 **백악관 문서 위조** 문제가 발생할 위험이 있습니다.
